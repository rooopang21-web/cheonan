1추진 배경

현재 부서별 민원 처리 현황을 월말마다 수작업으로 취합하고, 여러 파일의 수치를 복사하여 보고자료를 작성하고 있음.

핵심 필요성
집계 기준의 차이와 반복 확인을 줄이고, 긴급 민원 및 장기 미처리 건을 보다 쉽게 파악할 수 있는 방식 검토 필요.

2현황 및 문제점

01
수작업 중심 취합

여러 파일의 수치를 복사해 월말 보고자료를 작성.

02
집계 기준 불일치

부서별 집계 기준이 일부 달라 재확인이 반복됨.

03
주요 민원 식별 어려움

긴급 민원과 장기 미처리 건을 한눈에 파악하기 어려움.

3추진 목표

제안사항
  • 부서별 입력 및 집계 방식 표준화
  • 기본 민원처리 KPI 자동 산출 기반 마련
  • 주요 민원 현황 조회 편의성 개선
  • 월별 변화 추이를 시각적으로 확인
정량적 성과목표는 추가 확인 필요

4주요 추진과제

TASK 01
공통 입력 양식

부서별 입력항목과 형식을 통일하여 집계 기준 차이를 줄이는 방안 검토.

TASK 02
기본 KPI 자동 계산

입력 데이터를 기반으로 기본 민원처리 지표를 자동 산출하는 기능 검토.

TASK 03
다중 필터

부서, 처리상태, 긴급도를 기준으로 필요한 현황을 빠르게 조회.

TASK 04
월별 추이 차트

월별 민원처리 현황 변화를 차트 형태로 확인할 수 있도록 구성.
